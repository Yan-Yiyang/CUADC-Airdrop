# 0.2.0 发布说明

本版本更新统一任务运行、QGroundControl视频、投放判据、离线诊断及工具仓库组织。

## 主要变化

- 统一real/SITL入口，按参数选择采集、识别、真实或模拟释放、侦查上传及投放后降落阶段。
- 起飞前完成YOLO与OCR模型链路预热；地面图像保留预览，不进入任务识别与保存缓冲。主进程OpenCV默认4线程，并提供配置覆盖。
- QGC中文合成视频展示任务阶段、目标观测、实时预测和投放发送状态；目标截图保持至同编号更新，飞掠完成按任务进度锁存。
- 实时预测与成功投放时的历史模型预测分开。投放按预测沿向过零且横向容限合格优先判定；过零后水平5米近靶判定及沿向严格超过5米的最后兜底依次生效。
- 改善外部任务替换/进度同步、命令超时门控、尾帧与OCR排空和失败清理。
- 仿真世界/机型与离线相机标定拆为独立工具仓，主仓固定子模块版本；新增检测与RTP时钟诊断工具。
- 清理文档、旧入口和私人材料引用，增加Git索引链接及注释/docstring卫生检查。

## 升级提示

Python要求为3.14或更高（旧版本未经验证），依赖由uv管理。克隆时使用`--recurse-submodules`；已有仓库执行`git submodule update --init --recursive`。

运行参数与安装方法以本版本README和手册为准。独立工具的CLI与主任务入口分别维护，不再使用已删除的examples或旧tools导入路径。

## 验证边界与已知问题

离线回归、合成几何、历史素材完整软件回放和本地视频测试分别覆盖相应范围，不证明当前版本实际摄像头精度、现场端到端时延或物理挂架释放成功。固定历史飞机不会响应新生成航线或新的释放时刻。
