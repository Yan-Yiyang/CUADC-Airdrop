# 0.3.0 发布说明

本版本完成 30 FPS 视频接收、分层存储、TensorRT 感知管线、QGroundControl 合成推流、遥测源时标对齐以及仿真非零相机畸变与随机化能力的全面升级，并将默认推理后端切换为 TensorRT FP16，保留显式 PyTorch 备用路径。

## 主要变化

- **TensorRT FP16 默认感知管线与显式 PyTorch 备用**：
  - 接入 YOLO 静态输入 TensorRT 引擎推理（脱离 `ultralytics`、使用设备端预处理与 `torchvision.ops.nms` 后处理）与 PP-OCRv6 动态 profile TensorRT 引擎推理，新增共享运行时与伴随 `.engine.manifest.json` 摘要、张量规格及运行环境强校验。
  - TensorRT OCR 改为同进程共享引擎线程池（单次反序列化、按工作线程克隆独立 `IExecutionContext` 与非默认 CUDA 流），避免多进程重复加载 CUDA 上下文与权重导致的主机内存与显存倍增，并限制加载期 PyTorch CPU 线程与狭长裁切输入长边上限（`det_max_side_len=960`）。
  - 新增 `python -m airdrop.run build-trt` 离线构建、PyTorch 数值核验与原子发布子命令；默认编译及加载目录统一为 `models/trt/`（由 `.gitignore` 排除），引擎或清单缺失、摘要或环境不匹配时直接报错中止，不做静默回退。
  - `mission` 与 `replay` 新增 `--backend {trt,pytorch}` 快捷切换及 `--model`、`--ocr-models-dir`、`--ocr-det-model`、`--ocr-rec-model`、`--ocr-workers` 显式覆盖参数，保持历史飞行记录 `config_snapshot.json` 严格兼容。
  - 移除 `onnxruntime-gpu` 依赖与 ONNX 方向分类分支，默认关闭方向分类会话（`cls_engine="off"`），精简 `pyproject.toml` 与 `uv.lock` 并将 `onnx`/`tensorrt` 归入 `trt` 可选依赖组。
- **PyAV 单路采集、冷热分层视频存储与磁盘积压优化**：
  - 采用 PyAV 单路解复用、TS 分段归档与有界热/冷分层缓存；以写端提交水位和消费者游标替代后台持续重解码校验，实时追帧阶段即时释放已消费热帧并保持零冷读，同时支持封闭段 `.rap.jsonl` 关键帧字节偏移索引、只读零拷贝读取及可选起飞前冷读逐像素抽检（`PreflightConfig.verify_cold_read`）。
  - 感知帧快照复用去畸变只读内存并异步落盘裁切图；OCR 磁盘积压索引启用 SQLite WAL 模式并异步清理已确认文件。
- **QGC 合成推流渲染与收尾优化**：
  - 优化渲染键、字形缓存、背景填充与发布副本复用，保留媒体时间戳并完整排空编码末帧，降低 30 FPS 联合负载下的渲染和内存拷贝开销。
- **遥测源时标对齐与流式标定**：
  - 默认启用位置与姿态字段源时标内插（`TelemetryConfig.source_time_alignment=True`）并统一消费同参照标定延迟；支持地面高频标定采集，同步更新 `vendor/airdrop-calibration` 支持 TS 航次恢复与全程流式标定。
- **仿真子仓非零畸变、随机化与联合仿真资源隔离**：
  - `vendor/airdrop-sim` 新增可配置非零相机畸变（`D0`/`D1`/`D2` 及适配 Gazebo 8 `ogre2` 的 Brown-Conrady 系统插件 `airdrop::CameraDistortion`）与第二轮可复现随机数字生成（支持有效编码 `00`）。
  - `run_sitl.sh` 支持树外独立运行目录的 `USE_CUDA_GST=false`、`UDP_HOST`/`UDP_PORT`、`CUSTOM_WORLD_DIR`、`CUSTOM_VEHICLE_DIR`、`PX4_DAEMON=1`、`DISABLE_RC_LOSS=1` 及 `compat-build` 插件自动加载，便于 WSL 与 Windows 联合仿真时的显存与内存隔离。

## 升级提示

- 要求 Python ≥ 3.14，依赖由 `uv` 管理。安装或升级默认 TensorRT 运行与构建依赖请执行 `uv sync --extra trt`；首次升级或更换 GPU / TensorRT 版本后，须先准备好 `models/` 下的源权重并运行 `python -m airdrop.run build-trt --target all` 在本机 `models/trt/` 生成引擎与伴随清单。
- 暂未构建 TensorRT 引擎或需要对照验证时，请在 `mission` / `replay` 中显式传入 `--backend pytorch`。`replay` 省略 `--backend` 时仍原样保留 `config_snapshot.json` 中的录制权重配置。
- 本版本同步更新了 `vendor/airdrop-sim` 与 `vendor/airdrop-calibration` 子模块指针；已有仓库升级后请执行 `git submodule update --init --recursive`。升级不自动上传或启动操作手任务。
