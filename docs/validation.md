# 待完成的工程验证

以下项目描述仍需完成的验证条件，不代表当前版本已经通过实机或飞行验收。基本性能和视频诊断方法见[性能度量](performance.md)，运行生命周期见[运行说明](runtime.md)。

定位精度、聚类比较、姿态与时间轴的可复用诊断方法见[定位诊断](simulation_world.md#定位误差与时间对齐诊断)。已退役的本地原始验证数据不再作为可直接重跑的输入；后续验收重新采集，不以方法文档替代场景验证。

## 入口与依赖

- 补足真实入口的生命周期与外部资源替身接缝，验证业务调用链和失败收尾；仅验证替身不能证明业务覆盖。
- SDK迁移需要隔离验证Python与asyncio兼容性、连接订阅、任务与挂架接口、原点与风数据、错误分类和关闭行为。先保持超时门控与恢复语义，再运行离线和SITL回归；不以只改依赖版本号代替迁移。安装依赖需遵循仓库授权约定。
- 手眼后端切换前检查安装包实际导出的API与最小几何调用，覆盖绝对位姿/相对运动约定、标签二义性、杆臂、退化和含噪场景；保留现有产物兼容性与回退。

## 视频与回放

- 持续验证墙钟/VFR 发布在慢合成与邮箱覆盖条件下的 RTP 媒体时间、重复时间戳、帧数、容器时长及编码器重启；长时钟跳变、跨编码器和外部网络仍需独立覆盖。
- 验证 EOF 排空末帧与超时强制退出两种收尾；保留真实 BrokenPipe 和编码器重启竞态证据，不能通过吞掉异常宣称发布全程无故障。
- 在同一完整负载下联合记录发送包时间、接收日志、同次编码流与窗口录屏，区分合成时序、网络接收、解码、显示和录屏开销。
- 将完整任务回放适配为可配置输入，不依赖固定架次、固定帧数或旧提交。固定航迹回放不验证新航线的闭环响应。

## 仿真与设备

- 对当前版本进行完整SITL飞行与QGC联合复验，包含默认OCR并发、停止收尾和视频接收。
- 按机型回读参数，确认MAV实例与物理UART的对应关系、波特率、流模式和实际吞吐。
- 在视频开启、弱信号及任务传输负载下测实际遥测频率和时延，不能仅凭速率设置ACK判断成功。
- 先完成操作手任务同步、断连重连和视频接收的地面检查，再进行独立飞行、现场端到端时延与物理挂架验收。

每项验收记录软件和依赖版本、输入及配置、操作步骤、观测结果、失败恢复和覆盖边界。可复用方法进入文档；原始素材、设备参数备份和个人目录留在本地。
