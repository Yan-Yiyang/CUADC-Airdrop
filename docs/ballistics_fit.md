# 投放记录与弹道参数反演

本文档说明投放记录（位置/速度/姿态/风）与实测落点的配对方式、反演可识别的参数范围、
必须拒绝给出结论的情形，以及工具的使用方法。相关代码：`airdrop/ballistics/`、
`tools/fit_ballistics.py`；离线用例见 `tests/test_fit.py`。
进行投放试验或调整 `BallisticsConfig` 前请先阅读本文档。

## 密度基准

- 密度基准取记录的原点海拔：`ground_altitude_m = origin.alt_m − ground_z`
  （关闭 `air_density_isa` 时同样在投放海拔取一次常密度，见
  [`handbook.md`](handbook.md) §3.7.1）。同一站点内结果自洽。
- 记录缺原点时退回海平面基准，并在 `FitResult.warnings` 中告警。
- 修改密度基准、或在不同站点/海拔复用参数前应重新执行反演：`Cd` 会随密度差等比变化
  （`κ = Cd·A/m` 的相对关系不变）。

## 数据配对

- `DropRecord` 记录投放瞬间的位置、速度、姿态（欧拉角与四元数）、风、离地高度、
  NED 原点、目标点，以及判据的前推位置与预测落点。
- 实测落点由测量文件提供（`impacts.jsonl` / `.csv`，经纬度或 NED 均可，模板可生成），
  按**该条记录自己的原点**换算。
- **`ReleaseDecision.delay_s` 必须写入记录**：应记录判据当时实际使用的前推量，
  不能读取 runner 自身的 config（两者可以不同，如 judge 0.08、runner config 0.0）；
  延迟差异会被全部计入 `Cd`。

## 可辨识性

反演的核心是判断参数能否被数据辨识，而非残差能否减小（`ballistics/fit.py`）：

1. **质量不参与反演，由实测称重提供**：`FIT_PARAMETERS` 中不包含 `mass_kg`。
   数据可辨识量只有一个数 **κ = Cd·A/m**（`drag_k_per_m`）；给定实测质量后才有
   `Cd·A = κ·m`。重拟合时 `Cd` 与 `Cd·A` 随质量同比变化、`κ` 不变——因此质量必须实测，
   更换配重按 `κ' = Cd·A/m'` 重算即可（工具参数为 `MEASURED_MASS_KG`）。
2. **Cd 与迎风面积只能固定其一**（数据仅能辨识二者乘积）⇒ 同时拟合将被直接拒绝。
3. **释放延迟与阻力沿航迹方向高度相关**：同高同速条件下条件数可达 1e10，超过阈值即拒绝；
   拉开速度/高度后条件数可降至约 17、两参数误差回到 1e-3 以内。
   有风条件下二者更易分离（同地速、不同航向对应不同空速）；"无法分离"的验证用例
   应使用零风条件。
4. **常数偏差（测量点/目标点坐标错误）无法被任何参数吸收**：`bias_north/east_m`
   单独列出，并提示先核对坐标。

## 统计量与验证

- σ、相关性与条件数通过自实现的中心差分雅可比 + SVD 计算（`inv(JᵗJ)` 近奇异时结果不可用）；
  自由度 ≤ 0 表示 σ 无定义。
- 留一交叉验证默认开启——残差偏小最容易造成误判。

## 正演初始条件

`release_conditions` 仅包含两个修正项：一阶前推 `p + v·δ` 与机体坐标系挂点偏移
（经记录中的姿态转为 NED）。姿态在弹道计算中的用途仅此一处。

## 工具输出

`tools/fit_ballistics.py` 输出：

- 对照表：判据预测 / 反演后预测 / 实测（含沿航迹、垂直航迹分解）；
- `ballistics_fit.json` 报告；
- 可直接回填配置的 `BallisticsConfig(...)`。
